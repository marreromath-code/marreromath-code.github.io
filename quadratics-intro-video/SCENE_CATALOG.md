# Scene Catalog: Quadratic Functions Introduction (v2, Brilliant-inspired)

Design: Marrero Math website palette (cream #F9F7F2, navy #1A2744, gold #B8960C,
coral #E07A52), Fraunces headings + Inter body. Lesson patterns inspired by the
Brilliant screens in the Mobbin "Education" collection: top progress bar,
left-aligned lesson title, white cards, pause-and-predict option cards with a
3-second countdown, live sliders with a value bubble, algebra tiles, navy-header
tables, green "Correct!" / yellow "Incorrect" banners, "Why?" explanation card,
and Continue buttons that press before each transition. All animation is Manim.
